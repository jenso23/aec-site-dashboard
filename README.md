Project Summary: AEC Site Safety & Microclimate Monitor
This web application helps construction site managers monitor real-time microclimate conditions to prevent weather-related safety hazards, such as high-wind crane incidents and improper concrete curing temperatures. Built as a static frontend using HTML, Tailwind CSS, and JavaScript, the app connects to the public Open-Meteo Weather API via asynchronous HTTP GET requests using coordinates for active construction sites in Taipei. Upon receiving the JSON payload, the JavaScript client parses current and 24-hour hourly forecast metrics for temperature, wind speed, and precipitation. It evaluates these values against site safety thresholds to display dynamic status alerts in KPI cards and renders an interactive dual-axis line chart using Chart.js, enabling rapid, data-driven field decisions without manual weather lookups.
